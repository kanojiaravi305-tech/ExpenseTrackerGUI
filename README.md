# Expense Tracker

A simple web application to manage and track your daily expenses. Built as a college project for the **Next Generation Database (NGD)** subject to demonstrate how a web application connects with and stores data in a **MongoDB NoSQL database**.

---

## Technologies Used

| Layer     | Technology            |
|-----------|-----------------------|
| Frontend  | HTML5, CSS3, JavaScript |
| Backend   | Python (Flask)        |
| Database  | MongoDB (NoSQL)       |
| Driver    | PyMongo               |

---

## Required Software

1. **Python 3** (version 3.7 or later)
   - Download: https://www.python.org/downloads/
2. **MongoDB Community Server**
   - Download: https://www.mongodb.com/try/download/community
   - Make sure the MongoDB server is installed and running locally on port `27017`.

---

## Setup and Installation Steps

1. **Download or create the project folder.**

2. **Open the terminal** (Command Prompt / PowerShell / Terminal) **inside the project folder.**

3. **Install Python dependencies:**

   ```
   pip install -r requirements.txt
   ```

4. **Start the MongoDB server.**

   - On Windows, make sure the MongoDB service is running, or start it manually:
     ```
     mongod
     ```
   - On macOS/Linux:
     ```
     sudo systemctl start mongod
     ```

5. **Run the Flask application:**

   ```
   python app.py
   ```

6. **Open this URL in a browser:**

   ```
   http://127.0.0.1:5000/
   ```

## How MongoDB is Used in This Project

- **MongoDB** is a NoSQL database that stores data in flexible JSON-like documents instead of rows and columns (like SQL databases).
- This project uses **PyMongo**, the official Python driver for MongoDB, to connect Flask with the MongoDB server.
- A database called `expense_tracker_db` is created automatically when the first expense is added.
- Inside this database, a collection called `expenses` stores all expense records.
- Each expense is stored as a **document** with the following structure:

  ```json
  {
    "_id": "ObjectId (auto-generated by MongoDB)",
    "title": "Lunch",
    "amount": 250.0,
    "category": "Food",
    "date": "2026-08-07",
    "description": "Lunch with friends",
    "created_at": "2026-08-07T15:30:00"
  }
  ```

- **CRUD operations** are performed using PyMongo methods:
  - `insert_one()` — to add a new expense
  - `find()` — to retrieve all expenses
  - `find_one()` — to retrieve a single expense by ID
  - `update_one()` — to update an existing expense
  - `delete_one()` — to delete an expense

## Features

1. **Add Expense** — Fill a form to add a new expense (title, amount, category, date, description).
2. **View All Expenses** — See all saved expenses in a table with serial numbers.
3. **Edit Expense** — Click the Edit button to modify any expense.
4. **Delete Expense** — Click the Delete button (with confirmation) to remove an expense.
5. **Total Expenses** — The total amount of all expenses is calculated and displayed.
6. **Search** — Search expenses by title or category.
7. **Category Filter** — Filter expenses by selecting a specific category.
8. **Validation** — Both client-side (JavaScript) and server-side (Flask) validation.
9. **Flash Messages** — Success and error messages after every action.
10. **Responsive Design** — The website works on both desktop and mobile screens.
